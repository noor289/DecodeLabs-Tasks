# Data Analytics Project 2 – Exploratory Data Analysis (EDA)

## Overview
This project focuses on performing Exploratory Data Analysis (EDA) to understand the dataset by identifying patterns, trends, and key insights. The goal is to transform raw data into meaningful information using analytical techniques.

## Objectives
- Analyze dataset structure and variables  
- Calculate basic statistics (mean, median, count)  
- Identify trends and patterns  
- Detect outliers and anomalies  
- Summarize key observations  

## Methodology
1. **Data Understanding**
   - Loaded and explored the dataset
   - Checked data types and structure  

2. **Data Cleaning**
   - Handled missing or inconsistent values  
   - Removed duplicates (if any)  

3. **Statistical Analysis**
   - Calculated descriptive statistics:
     - Mean
     - Median
     - Count  

4. **Exploratory Analysis**
   - Examined distributions of variables  
   - Identified trends and relationships  
   - Detected outliers  

## Key Findings
- Data showed noticeable patterns across key variables  
- Certain features had strong relationships  
- Outliers were identified, which may impact analysis  
- Distribution of data helped in understanding overall behavior  

## Conclusion
EDA is an essential step in data analysis. It helps uncover hidden insights and prepares the data for further modeling or visualization. This project strengthened analytical thinking and provided hands-on experience in interpreting real-world data.

## Skills Gained
- Data analysis  
- Descriptive statistics  
- Critical thinking  
- Pattern recognition
